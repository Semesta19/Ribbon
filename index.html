Titik terpilih

Ketuk titik di mode Bentuk atau Lipat untuk memilihnya. Puntir di atas 0 membalik sisi kain melewati garis lipat lurus di titik itu; angkanya sudut garis terhadap pita (90° = melintang, 45° = miring). Pakai dua titik untuk membuat bagian pita yang terbalik di antaranya.
